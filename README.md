# TMDB-Movie-Analysis
My first EDA Project in data analysis by python and google colab. 
An Exploratory Data analysis(EDA) investigating the factors that drive movie popularity. I analyzed 4000 movies to see if high rating crrelate with high popularity.

###Key insights
**The Hype Gap:** I found a very low correlation (0.08) between Rating and popularity.High quality does not guarantee fame!
**Post-2020 Surge:** There is a massive spike in popularity scores after 2020, likely due to straming boom during the pandemic.
**Overhyped vs Hidden Gems:** Identified movies like ' War of the worlds' that remain highly popular despite lower ratings.

###Tools used
Python (Pandas, Matplotlib, Seaborn)
Google Colab
